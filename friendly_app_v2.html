The most common cause is a "printed" PDF. When someone uses File → Print → Save as PDF, the result contains only images — not readable text. Our tool cannot process image-based PDFs.

Fix: Go back to the portal and use the official Download button on the website. The original downloaded PDF has readable text and will work correctly.

• Financial Year (FY) — the year the income was earned. Example: FY 2024-25 = April 2024 to March 2025. Used for GST filings.

• Assessment Year (AY) — the year you file the Income Tax Return for the previous year's income. Example: AY 2025-26 = the ITR you file in 2025 for income earned in FY 2024-25.

So if you earned income in FY 2024-25, your GST reports use "FY 2024-25" and your IT Recon uses "AY 2025-26".

🚀 Quick Start Guide
1
Download files from the GST portal
Go to gst.gov.in and download your GSTR-1 (sales), GSTR-2B (purchases), and GSTR-3B (monthly returns) for the year. Or use Auto Download to skip this step.
2
Upload & run GST Reconciliation
Go to the GST Reconciliation tab, enter the client name and year, upload the files, and click Run. Takes about 1-2 minutes.
3
Download & review your Excel report
Once done, a download button appears. Save the Excel file. The report clearly shows everything reconciled — and highlights anything that needs attention.
4
Optionally run Income Tax Recon & Combined Report
For a full ITR readiness picture, also run the Income Tax Recon tab (upload 26AS, AIS, TIS from incometax.gov.in), then use the Full Combined Report tab to merge both into one master workbook.
